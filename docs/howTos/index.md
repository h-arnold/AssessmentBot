# Using Assessment Bot

Assessment Bot marks students' Google Slides or Google Sheets work against a completed
reference version. These guides cover the tasks you will repeat.

## Choose a guide

- [Prepare and distribute tasks](./prepare-tasks/index.md) — create the template, tag the
  parts to assess and attach it to a Google Classroom assignment.
- [Run an assessment](./run-an-assessment/index.md) — create an assignment definition and
  start a marking run for a class.
- [View results](./view-results/index.md) — read averages, heatmaps and task feedback.
- [Manage assignment definitions](./manage-assignment-definitions/index.md) — update or
  remove saved definitions.

If you have not set up Assessment Bot yet, start with the [setup guide](../setup/README.md).

## Understand the scores

For an explanation of averages, weightings and the `N`, `E` and `Excluded` states, see
