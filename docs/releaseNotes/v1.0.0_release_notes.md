# 🚀 v1.0.0

Assessment Bot v1.0.0 is a major release. It replaces the Google Sheets-bound Admin Sheet with a standalone Google Apps Script (GAS) Web App powered by a new React interface.

This makes installation and future updates substantially simpler: Assessment Bot is deployed once as a web app rather than copied into, and maintained through, a bound spreadsheet script. It also provides the foundation for richer application features beyond the limits of the old spreadsheet interface.

## ⚠️ Breaking change: Web App deployment

v1.0.0 is not an in-place update for an existing Admin Sheet installation. The old **Assessment Bot → Settings → Update Version** route no longer applies.

- Deploy the v1 GAS bundle as a Web App, then open its web-app URL to use Assessment Bot.
- The web app runs as the signed-in user and is intended for Google Workspace-domain deployment.
- The legacy Admin Sheet UI, update manager, and bound-script workflow have been removed.
- Plan the move as a new v1 deployment rather than a spreadsheet-script upgrade. Review the data you need to retain before retiring an existing Admin Sheet installation.

## ✨ Highlights

- **A modern browser-based application.** A React frontend now replaces the spreadsheet administration surface, with dedicated navigation for Classes, Assignments, Heatmaps, and Settings.
- **Simpler deployment and updates.** The builder packages the backend and frontend into one clasp-ready GAS bundle, removing the old version-selector and sheet-cloning update process.
- **Classes and assessment workflow.** Browse classes by year group, open a class overview, select Google Classroom assignments, and start an assessment from the web app. Create a new assignment definition or link a suitable existing definition during the flow.
- **Assignment management.** View, sort, filter, edit, and delete assignment definitions from a single page.
- **Visual analysis.** Per-class task heatmaps show Completeness, Accuracy, and SPaG for every student and task. A Heatmaps builder can combine selected assignments by class and topic.
- **Inspectable evidence.** Select a heatmap cell to view the AI reasoning and the student's original image, text, or table response.
- **Reference-data management.** Manage cohorts, year groups, and assignment topics from Settings, including natural year-group ordering.
- **Safer class management.** Create, edit, delete, filter, and sort classes, including queued bulk actions with progress and cancellation feedback.
- **Application authentication.** Access is now gated by either Google Group membership or a Script Properties user list, with `admin` and `user` roles. A fresh deployment assigns the first eligible interactive user as administrator; admins can configure access in Settings.
- **Configurable LLM service connection.** Configure the Assessment Bot LLM Service URL and API key from the application settings.

## 🛠️ Under the hood

- The backend is now organised as a GAS web-app API with a single validated frontend transport boundary.
- The project has separate GAS backend, React frontend, and Node.js builder runtimes, with the frontend inlined into the deployed HtmlService output.
- Data transport, authorisation, and configuration boundaries now have explicit validation and fail-closed error handling.
- The assessment workflow, document parsing, Google Classroom integration, Drive handling, spreadsheet formula assessment, and feedback generation continue to underpin the new interface.
- The release adds broad automated coverage across backend, frontend unit, and browser end-to-end tests.

## ⬆️ Moving to v1.0.0

1. Build and deploy the v1 bundle to a Google Apps Script project as a Web App.
2. Confirm that the deployment executes as the user accessing the app and is restricted to the intended Google Workspace domain.
3. Open the Web App URL while signed in with the intended administrator account. On a fresh installation, that first eligible interactive user becomes the initial administrator.
4. In Settings, configure the Assessment Bot LLM Service and review the application authentication provider and authorised users.
5. Add or manage classes, then begin assessments from the Classes area.

Do not use the retired Admin Sheet update menu or attempt to install v1 into an existing bound Admin Sheet script.
