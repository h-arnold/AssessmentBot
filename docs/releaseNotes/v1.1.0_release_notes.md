# 🚀 v1.1.0

Assessment Bot v1.1.0 builds on the v1 Web App with smoother assessment workflows, clearer heatmap reporting, and easier access to student work.

## ✨ Highlights

- **Open student source documents from task previews.** Open the original Google Slides or Sheets submission directly from a preview when a supported source is available.

![Task preview showing the open-source-document link in the card header](https://raw.githubusercontent.com/h-arnold/AssessmentBot/v1.1.0/docs/releaseNotes/images/v1.1.0-task-preview-link-example.png)

- **Re-run assessments from class heatmaps.** Start a new assessment from an assignment heatmap, reusing the definition from the previous assessment where possible.
- **Clearer zero-weight score reporting.** Zero-weight tasks remain visible but do not affect aggregate averages, and the interface identifies when a score is excluded. Unknown task IDs are ignored with diagnostics.
- **Separate student names into Forename and Surname.** The Student Averages and Task Heatmap tables now provide independently sortable name columns.
- **More dependable assignment-definition workflows.** Recovery and editing flows are more robust, document URLs remain editable after a document change, and stored date baselines are normalised consistently.
- **Improved Slides parsing and matching.** More robust extraction and matching helps handle malformed tags and ambiguous submissions reliably.
- **Quieter handling of missing scores.** Absent assessment criteria no longer produce unnecessary warnings.

## 🛠️ Reliability and maintenance

- Updated the vendored JsonDbApp dependency.
- Added deterministic synthetic analysis test data to support repeatable analysis checks.
- Continued strengthening regression coverage across assessment, heatmap, assignment, and document-parsing workflows.
